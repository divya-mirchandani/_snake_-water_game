
# Snake Water Gun Game 🐍💧🔫

A simple command-line game built using Python where you play against the computer in the classic Snake, Water, and Gun game.

## Rules

- Snake (1) drinks Water (-1) → Snake wins
- Water (-1) drowns Gun (0) → Water wins
- Gun (0) shoots Snake (1) → Gun wins
- If both choices are the same, the game is a draw.

## Features

- Computer generates a random choice.
- User can choose Snake, Water, or Gun.
- Displays the winner after each round.
- Beginner-friendly Python project.

## Technologies Used

- Python 3
- Random Module
